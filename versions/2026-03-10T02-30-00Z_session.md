## Changes Made This Session

### 1. Added Chatbot Widget

#### New component: `Chatbot.js`
- Floating chat button fixed to the bottom-right corner
- Opens a slide-up chat window with header, message area, and text input
- Keyword-matching Q&A engine that answers questions about the portfolio owner
- Clickable suggestion chips shown on first open for quick interaction
- SVG icons for the toggle button (chat bubble / close X) and send button
- Fully theme-aware — inherits all colors from CSS custom properties

#### New data file: `data/chatbot.js`
- Contains bot name, greeting message, suggestion chips, and Q&A knowledge base
- 12 Q&A entries covering: intro, skills, experience, current role, contact info, education, location, Salesforce expertise, Agentforce/Data Cloud, availability, hobbies, and greetings
- Fallback response for unmatched queries

### 2. Chatbot Styles Added to `globals.css`
- `.chatbot-toggle` — fixed-position circular button with theme accent color and hover scale effect
- `.chatbot-window` — bordered panel with slide-up animation (`chatSlideUp` keyframe)
- `.chatbot-header` — header bar with green status dot and bot name
- `.chatbot-messages` — scrollable message container with thin scrollbar
- `.chatbot-msg-bot` / `.chatbot-msg-user` — styled message bubbles (bot = card color, user = accent color)
- `.chatbot-suggestions` / `.chatbot-chip` — pill-shaped suggestion buttons matching the site's tag style
- `.chatbot-input-bar` / `.chatbot-input` / `.chatbot-send` — input area with send button
- Mobile responsive via `@media (max-width: 480px)` — full-width window on small screens

### 3. Build & Integration Updates
- `build.js` — added `components/Chatbot.js` to the COMPONENTS array
- `index.html` — added `<script src="data/chatbot.js">`, added `chatbot: CHATBOT` to CONTENT object, added `<Chatbot/>` to the App component
